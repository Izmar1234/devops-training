# TP Shell — La Forge Chronologique

Ce projet réalise la création et la réorganisation de fichiers horodatés
avec des scripts Bash.

## Contenu du projet

- `creation_script.sh` : crée N fichiers horodatés.
- `reorganization_script.sh` : réorganise et renomme les fichiers.
- `lancer_les_9_cas.sh` : lance les neuf combinaisons demandées.
- `test_tp.sh` : vérifie automatiquement le fonctionnement du projet.

## Donner les droits d'exécution

```bash
chmod +x *.sh
